Privacy Policy

Last updated: 18 November 2026

What we collect

When an account owner connects TikTok, the app receives from TikTok: an access token and refresh token, the account's open ID, and basic profile information (display name and avatar) under the user.info.basic scope. It uses the video.publish scope only to post clips to that same account.

For live streams, the app reads the public chat of the stream anonymously to count message volume. It does not store chat usernames beyond the processing of a clip.

How it is used

Tokens are used only to publish clips the operator has made to the account that granted permission, and to check the status of those posts. Nothing else is done with them.

Where it is stored

Tokens are stored locally on the operator's own computer, in a file readable only by the operator. They are not sent to any server other than the platform's own API.

Sharing

No data is sold, rented or shared with third parties, and none is used for advertising.

Retention and deletion

Tokens are kept until the connection is removed. You can revoke access at any time in TikTok (Settings → Security → Manage app permissions); the stored tokens then stop working and are deleted by the operator on request.
